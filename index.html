PROJECT SYNAPSE RULEBOOK

Mission

Move all three drones from their START squares to their own TARGET squares, then read off the 4-digit override code. The team may choose any drone for the very first move; after that, the board decides who moves.

DroneStartTarget
Red RoverA1A8
Blue ProbeB1D8
Yellow OrbiterC1H8

Movement

Every move is exactly one square up, down, left or right. No diagonals, and no leaving the board. Two drones can never occupy the same square.

Burned Path: a drone may never land on a square it has already occupied during the current run. Its own START square counts as burned from the beginning. Squares that other drones have visited are fine.

The Telemetry Chain

The color of the square a drone just landed on decides which drone must move next. A Blue square means the Blue Probe moves next, even if the Red Rover just moved.

Targets and locking

A drone that lands on its own TARGET locks permanently and becomes an immovable wall.

Lock order: the Blue Probe and Yellow Orbiter may lock in either order. The Red Rover must lock last.

A drone may pass through an empty TARGET that belongs to another drone; it counts as a blank square.

Free choice: TARGET squares have no color, so after any lock or any target landing, the team picks which active drone moves next. In this game: click the drone you want to move, then click a highlighted square. START squares are off-limits to every drone except the one that began there, so they never give a free choice.

The override code

Four digits are hidden on the board. The code is the order in which a drone first lands on them. Landing on a digit that is already recorded adds nothing, but its tile color still decides who moves next. The code is extracted only when all three drones are locked and all four digits have been recorded.

Crashes

Any of these crashes the sequence: all drones return to START and a fresh run begins.

  • Hazard Strike: landing on an Ion Storm, Asteroid or Gravity Well.
  • Memory Loop: being forced onto a square that drone has already visited.
  • Logic Paradox: the chain names a drone that has no legal move (edges, other drones, hazards, its own burned path, or it is already locked).
  • Restricted Zone Breach: landing on another drone's START square.
  • Launch Sequence Violation: the Red Rover lands on its TARGET while the Blue Probe or Yellow Orbiter is still unlocked.

Every-turn checklist

  1. Move one square; check it is not a hazard, another drone's START, a burned square or an occupied square.
  2. If it is a digit you haven't recorded yet, add it to the code.
  3. If it is the drone's own TARGET, lock it (Red only if both others are locked).
  4. Read the color to find who moves next. On a TARGET, the team chooses.
  5. Check that the next drone has at least one legal move.
